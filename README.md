## O que é

Um kit gratuito para usar o Claude como escritório: escrever documentos, montar apresentações, criar peças de design e, em alguns planos, painéis de dados e animações. Serve para quem trabalha sozinho ou em equipe pequena e cansou de explicar a marca e o negócio toda vez. O kit traz um modelo de "quem eu sou" para colar num Projeto do Claude, prompts prontos para cada ferramenta e um checklist do que tem em cada plano. Para usar, basta uma conta no Claude (a grátis já serve para Docs, Slides e Design) e um navegador.

## O processo, do início ao fim

🧠 = você no Claude · ⚙️ = nada para rodar (é texto para copiar)

| # | Passo | O que fazer | Arquivo do kit |
|---|---|---|---|
| 1 | Contexto | Projetos › Novo projeto › cole as Instruções preenchidas (ou deixe o Claude te entrevistar) | `kit/contexto/instrucoes-do-projeto.md`, `kit/prompts/01-entrevista-contexto.md` |
| 2 | Marca | Anexe PDF da marca, prints do site ou o logo e peça o design system; confira as cores | `kit/prompts/02-design-system.md`, `kit/design-system-modelo.md` |
| 3 | Primeiro modelo | Faça a peça que você mais repete (proposta, documento, post, painel, animação) | `kit/prompts/03` a `07` |
| 4 | Reusar | A peça aprovada vira "Modelo de …" no Projeto; as próximas saem dela | `kit/prompts/08-reusar-modelo.md` |
| — | Antes de compartilhar | Confira plano, números e com quem compartilha | `kit/checklist-planos.md` |

## O que tem em cada plano (04/11/2026)

Docs, Slides e Design: todos os planos, inclusive o grátis. Dashboards: beta, só planos pagos. Motion: beta, só Team e Enterprise. Fonte: [claude.com/features/artifacts](https://claude.com/features/artifacts).
