# Prompt 7 — The idea in motion (Claude Motion)

**Plan:** Motion is in **beta** and available only on **Team and Enterprise** plans (it’s enabled by default on Team; on Enterprise, the owner enables it). It’s not available yet on Free, Pro, or Max.
**What it is:** A short animation made with code (text, charts, shapes, and images) that plays like a video and downloads as an MP4. It doesn’t use a video generator: it doesn’t create footage or AI-generated people. Change a word, a number, or the timing, and everything else stays the same.
**Where:** Artifacts tab › Motion model, type `/motion` in the message box, or “Output” › Motion.

```
/motion Turn this report into a 30-second animation for the team meeting.
- Use the [NAME] design system.
- Show only 3 numbers: [A], [B], [C], each with a label and a comparison to last month.
- Pace: one number every 8 to 10 seconds, with time to read.
- End with a sentence: [next step].
[PASTE THE REPORT OR ATTACH IT]
```

**Adjustments:** “make number 2 bigger,” “hold the last sentence for 2 more seconds,” “replace ‘customers’ with ‘patients.’” To continue working on it, open it in the video editors Claude lists during export.
