# Prompt 5 — Branded design pieces (Claude Design)

**When to use:** post, flyer, invitation, one-pager, sales page, screen prototype.  
**Where:** Artifacts › Design tab (choose your design system) or in the conversation. In Claude Code: `/design`.  
**Plan:** Design is available on all plans, including the free plan.

```
Using the [NAME] design system, create [a square post / an A4 flyer / a sales page] about:
[topic in one sentence].

- Goal: [what the person should do after seeing it — e.g., "message us on WhatsApp"].
- Audience: [who will see it].
- Text: a title of up to 8 words, 1 supporting sentence, 1 call to action.
- Give me 3 side-by-side versions with different layouts; I’ll choose one, and we can refine it.
- If you need an image that isn’t in the design system, describe it and ask me first.
```

## Missing a brand image?
Not every site has a photo, texture, or background for every need. Ask Claude to describe the missing style
("abstract background in the brand colors, no text") and generate it with the image generator you already use, or ask
for a graphic pattern made with code (shapes, gradients, icons) that Design itself can draw. Save the
approved images in the Project so you can reuse them.

## Inspiration
Want a different style? Gather 3 screenshots of layouts you like and ask: "use these screenshots only as
composition references; keep my colors and fonts."
