# Prompt 8 — Reuse: the first good one becomes a template (step 4)

The real benefit starts with the second piece. When a proposal, report, or post turns out well,
turn it into a template.

## Save
```
This [proposal / presentation / document] was approved. Write a text-based “template” for it:
structure (sections and order), length of each part, tone, what stays fixed, and what changes for each client.
I’ll save it in the Project as “Template for [name].”
```
Paste the result as a file in the Project (or in Instructions, if it’s short).

## Use
```
New [proposal] for [client], matching the “Template for [name].”
What changes: [new details / meeting notes].
Show only what changed compared with the template before putting everything together.
```

## Share with the team
Share › invite people with “view” or “edit” access. Everything starts out private. On Team/Enterprise plans,
an external public link is available only if the owner enables it in Organization Settings › Artifacts.
