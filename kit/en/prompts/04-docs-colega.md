# Prompt 4 — the document you work on with a colleague (Claude Docs)

**When to use:** internal policies, manuals, reports, monthly plans—anything you’d have put in Word, Google Docs, or Notion before.
**Where:** Artifacts tab › Docs, or ask in a conversation inside your Project.
**Plan:** Docs is available on every plan, including the free plan. The team can edit together in the same document.

## Start a document
```
Create a document: [E.g., "Front desk manual — how to confirm appointments via WhatsApp"].
Audience: [who will read it]. Length: [1 page / 3 pages].
Before writing, ask me up to 3 questions about what you don't know.
Use short headings, numbered step lists, and an "Attention" box for what goes wrong most often.
Leave [ ] wherever my information is missing instead of making it up.
```

## Work inside the document
- **Select a passage and ask:** "make it shorter," "turn it into a checklist," "explain it for someone who started yesterday."
- **Ask for a colleague-style review:** "comment on this document like a demanding manager: what's confusing,
  what's missing, what could cause problems." Claude adds comments to your choices.
- **Live chart:** with a spreadsheet or connected tool, ask "insert a chart of [X] by month"; it
  updates when you ask.

## Weekly routine (example)
```
Every Monday: read the "Weekly Plan" document, mark what’s done based on what I tell you,
and create the new week’s section with no more than 5 priorities.
```
