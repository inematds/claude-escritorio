# Kit — your office in Claude

Four steps, in order. Set it up once, use it every day.

| Step | What to do | File |
|---|---|---|
| 1. Context | Create a Project in Claude and paste in instructions about who you are | `contexto/instrucoes-do-projeto.md` (template), `contexto/exemplo/instrucoes-clinica.md` (example), `prompts/01-entrevista-contexto.md` (Claude interviews you) |
| 2. Brand | Build your design system from a PDF, website screenshots, or your logo | `prompts/02-design-system.md`, `design-system-modelo.md` |
| 3. First template | Create the piece you reuse most often | `prompts/03-slides-proposta.md`, `prompts/04-docs-colega.md`, `prompts/05-design-peca.md`, `prompts/06-dashboard-numeros.md`, `prompts/07-motion-explicativo.md` |
| 4. Reuse | The approved piece becomes a template for the next ones | `prompts/08-reusar-modelo.md` |

Before you start and before you share: `checklist-planos.md`.

Full guide: https://inematds.github.io/claude-escritorio/guia/
