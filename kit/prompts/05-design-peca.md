# Prompt 5 — peças de design com a sua marca (Claude Design)

**Quando usar:** post, folheto, convite, one-pager, página de venda, protótipo de tela.
**Onde:** aba Artifacts › Design (escolha o seu design system) ou na conversa. Pelo Claude Code: `/design`.
**Plano:** Design está em todos os planos, inclusive o grátis.

```
Com o design system [NOME], crie [um post quadrado / um folheto A4 / uma página de venda] sobre:
[assunto em 1 frase].

- Objetivo: [o que a pessoa deve fazer depois de ver — ex.: "chamar no WhatsApp"].
- Público: [quem vê].
- Texto: título com até 8 palavras, 1 frase de apoio, 1 chamada para ação.
- Me dê 3 versões lado a lado com layouts diferentes; eu escolho uma e a gente refina.
- Se precisar de imagem que não está no design system, descreva a imagem e pergunte antes.
```

## Faltou imagem da marca?
Nem todo site tem foto, textura ou fundo para tudo. Peça ao Claude para descrever o estilo que falta
("fundo abstrato nas cores da marca, sem texto") e gere com o gerador de imagem que você já usa, ou peça
um padrão gráfico feito em código (formas, gradientes, ícones), que o próprio Design desenha. Guarde as
imagens aprovadas no Projeto para reaproveitar.

## Inspiração
Quer outro estilo? Junte 3 prints de layouts de que você gosta e peça: "use estes prints só como
referência de composição; mantenha as minhas cores e fontes".
