# Prompt 4 — o documento com um colega (Claude Docs)

**Quando usar:** política interna, manual, relatório, plano do mês — o que antes ia para Word, Google Docs ou Notion.
**Onde:** aba Artifacts › Docs, ou peça na conversa dentro do seu Projeto.
**Plano:** Docs está em todos os planos, inclusive o grátis. A equipe edita junto, no mesmo documento.

## Começar um documento
```
Crie um documento: [Ex.: "Manual da recepção — como confirmar consultas pelo WhatsApp"].
Público: [quem vai ler]. Tamanho: [1 página / 3 páginas].
Antes de escrever, me faça até 3 perguntas sobre o que você não sabe.
Use títulos curtos, listas de passos numerados e uma caixa "Atenção" para o que dá errado mais vezes.
Deixe [ ] onde faltar dado meu, em vez de inventar.
```

## Trabalhar dentro do documento
- **Selecione um trecho e peça:** "deixe mais curto", "transforme em checklist", "explique para quem começou ontem".
- **Peça revisão como colega:** "comente este documento como um gerente exigente: o que está confuso,
  o que falta, o que pode dar problema". O Claude deixa comentários nas suas escolhas.
- **Gráfico vivo:** com uma planilha ou ferramenta conectada, peça "insira um gráfico de [X] por mês"; ele
  atualiza quando você pedir.

## Rotina da semana (exemplo)
```
Toda segunda: leia o documento "Plano da semana", marque o que foi feito com base no que eu contar,
e crie a seção da semana nova com no máximo 5 prioridades.
```
