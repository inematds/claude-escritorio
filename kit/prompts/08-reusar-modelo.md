# Prompt 8 — reusar: o primeiro bom vira modelo (passo 4)

O ganho de verdade vem da segunda peça em diante. Quando uma proposta, relatório ou post ficar bom,
transforme em modelo.

## Guardar
```
Esta [proposta / apresentação / documento] ficou aprovada. Escreva um "modelo" dela em texto:
estrutura (seções e ordem), tamanho de cada parte, tom, o que é fixo e o que muda a cada cliente.
Vou salvar isso no Projeto como "Modelo de [nome]".
```
Cole o resultado como arquivo no Projeto (ou nas Instruções, se for curto).

## Usar
```
Nova [proposta] para [cliente], igual ao "Modelo de [nome]".
O que muda: [dados novos / anotações da reunião].
Mostre só o que mudou em relação ao modelo antes de montar tudo.
```
