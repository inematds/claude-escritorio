# Prompt 8 — reutilizar: lo primero que queda bien se convierte en modelo (paso 4)

El verdadero beneficio llega a partir de la segunda pieza. Cuando una propuesta, un informe o una publicación quede bien, conviértela en modelo.

## Guardar
```
Esta [propuesta / presentación / documento] quedó aprobada. Escribe un «modelo» de ella en texto:
estructura (secciones y orden), extensión de cada parte, tono, qué es fijo y qué cambia con cada cliente.
Voy a guardarlo en el Proyecto como «Modelo de [nombre]».
```
Pega el resultado como archivo en el Proyecto (o en las Instrucciones, si es breve).

## Usar
```
Nueva [propuesta] para [cliente], igual al «Modelo de [nombre]».
Qué cambia: [datos nuevos / notas de la reunión].
Muéstrame solo lo que cambió con respecto al modelo antes de armar todo.
```

## Compartir con el equipo
Compartir › invita a las personas con permiso para «ver» o «editar». Todo empieza en privado. En los planes Team/Enterprise,
el enlace público solo se habilita si el propietario lo permite en Configuración de la organización › Artifacts.
