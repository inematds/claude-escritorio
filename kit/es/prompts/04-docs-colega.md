# Prompt 4 — el documento con un colega (Claude Docs)

**Cuándo usarlo:** políticas internas, manuales, informes, plan del mes: lo que antes iba a Word, Google Docs o Notion.  
**Dónde:** pestaña Artifacts › Docs, o pídeselo en la conversación dentro de tu Proyecto.  
**Plan:** Docs está disponible en todos los planes, incluso en el gratuito. El equipo edita en conjunto, en el mismo documento.

## Empezar un documento
```
Crea un documento: [Ej.: "Manual de recepción — cómo confirmar citas por WhatsApp"].
Público: [quién lo leerá]. Extensión: [1 página / 3 páginas].
Antes de escribir, hazme hasta 3 preguntas sobre lo que no sabes.
Usa títulos cortos, listas de pasos numerados y un recuadro de "Atención" para lo que sale mal con más frecuencia.
Deja [ ] donde falten datos míos, en vez de inventarlos.
```

## Trabajar dentro del documento
- **Selecciona un fragmento y pide:** "hazlo más corto", "conviértelo en una lista de verificación", "explícalo para alguien que empezó ayer".
- **Pide una revisión como colega:** "comenta este documento como un gerente exigente: qué está confuso,
  qué falta, qué podría causar problemas". Claude deja comentarios sobre tus decisiones.
- **Gráfico dinámico:** con una hoja de cálculo o una herramienta conectada, pide "inserta un gráfico de [X] por mes"; lo
  actualiza cuando se lo pidas.

## Rutina semanal (ejemplo)
```
Cada lunes: lee el documento "Plan de la semana", marca lo que se hizo según lo que te cuente
y crea la sección de la nueva semana con un máximo de 5 prioridades.
```
