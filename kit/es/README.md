# Kit — tu oficina en Claude

Cuatro pasos, en orden. Lo configuras una vez y lo usas todos los días.

| Paso | Qué hacer | Archivo |
|---|---|---|
| 1. Contexto | Crea un Proyecto en Claude y pega las instrucciones sobre quién eres | `contexto/instrucoes-do-projeto.md` (plantilla), `contexto/exemplo/instrucoes-clinica.md` (ejemplo), `prompts/01-entrevista-contexto.md` (Claude te entrevista) |
| 2. Marca | Crea tu design system a partir de un PDF, capturas del sitio o el logo | `prompts/02-design-system.md`, `design-system-modelo.md` |
| 3. Primer modelo | Crea la pieza que más repites | `prompts/03-slides-proposta.md`, `prompts/04-docs-colega.md`, `prompts/05-design-peca.md`, `prompts/06-dashboard-numeros.md`, `prompts/07-motion-explicativo.md` |
| 4. Reutilizar | La pieza aprobada se convierte en modelo para las siguientes | `prompts/08-reusar-modelo.md` |

Antes de empezar y antes de compartir: `checklist-planos.md`.

Guía completa: https://inematds.github.io/claude-escritorio/guia/
